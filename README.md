
# Sales Analysis with Python

## Project Overview
This project analyzes sales data using Python and pandas.
It generates business indicators, charts, Excel exports,
and automated commercial recommendations.

## Objectives
- Clean and prepare sales data
- Calculate total revenue and quantities sold
- Analyze revenue by product and month
- Visualize product performance
- Generate automated reports

## Technologies
- Python
- pandas
- Matplotlib
- Excel / CSV

## Generated Outputs
- `ventes_nettoyees.csv`
- `ca_par_produit.csv`
- `ca_par_mois.csv`
- `rapport_ventes.xlsx`
- `graphique_ca_produit.png`
- `part_ca_produit.csv`
- `recommandations_commerciales.txt`

## Dataset
The project uses a fictional sales dataset for demonstration.
All monetary values are illustrative.

## How to Run
1. Install the required libraries.
2. Place `ventes.csv` in the project directory.
3. Run:

   `python sales_analysis.py`
